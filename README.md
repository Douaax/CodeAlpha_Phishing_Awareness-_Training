# 🛡️ CodeAlpha Cybersecurity Internship

This repository contains the completed tasks for the **CodeAlpha Remote Cybersecurity Internship Program**.

## 📋 Tasks

### ✅ Task 1 — Basic Network Sniffer
Built a packet sniffer in Python using the **Scapy** library that captures live network traffic, extracts source/destination IP addresses, identifies protocols (TCP/UDP/ICMP), and displays raw payload data. Includes a minimal and an advanced version with deep packet inspection.

**Tech:** Python 3, Scapy

### ✅ Task 2 — Phishing Awareness Training
Developed a fully interactive, single-file HTML training module covering all aspects of phishing awareness — including how to recognize phishing emails and fake websites, social engineering tactics, real-world case studies (Google/Facebook BEC, MGM Resorts, Twitter hack), best practices, and an 8-question interactive quiz with scored results.

**Tech:** HTML, CSS, JavaScript

## 🚀 How to Run

**Task 1:**
```bash
pip install scapy
# Run as administrator/root
python Task1-Network-Sniffer/sniffer.py
```

**Task 2:**  
Open `Task2-Phishing-Awareness/phishing_training.html` in any browser.
